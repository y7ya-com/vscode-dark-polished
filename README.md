# VSCode Dark Polished Theme

Polished and comprehensive VSCode Dark Modern theme for Zed! 
Feel free to contribute where you see something has been missed.

## Variants

This extension ships three variants of the theme in one family:

| Variant | Window appearance | Description |
| --- | --- | --- |
| **VSCode Dark Polished** | Opaque | The original theme. Fully solid windows. |
| **VSCode Dark Polished (Blur Light)** | Blurred | Subtle glass: black window ~90% opaque; everything inside the window (editor, breadcrumbs/toolbar, search bar, sidebars, AI panel, terminal, tabs, input fields) is fully transparent, so the whole window reads as one uniform glass; the title bar and status bar keep the matching dark tint, the active tab carries a light-gray lift, file/search headers stay solid black, and the project-panel sticky row is a 70%-opaque frosted bar. |
| **VSCode Dark Polished (Blur Heavy)** | Blurred | Strong glass: black window ~70% opaque; same uniform transparent surfaces, light-gray active-tab lift, solid file/search headers, 70%-opaque frosted sticky row, plus softened borders and blended hover/selection states. |

All variants share the same text, icon, syntax, and terminal colors, so readability stays identical across them.

Switch variants in **Settings → Appearance → Theme** (or `zed: select theme`).

> **Note:** the blur variants rely on Zed's window transparency/blur support. On Linux a compositor with transparent window support is required; the blur effect may not work on all operating systems — this is a limitation of Zed's window implementation, not of the theme.
